# Part 1. 마케팅

## 1.1. 프로젝트 주제

### 핵심 주제

**「시즌성 주거 노마드(Seasonal Housing Nomad)」를 위한 문 앞 픽업 기반 마이크로 스토리지 + 위탁 대여 플랫폼**

- 단순 1인가구 전체가 아니라, **거주지가 일시적으로 비는 특정 상황**에 초점
- 타겟의 시작·종료 시점(Time)과 거주 행정동(Location)이 명확하여 시계열·GIS 분석 및 Meta Ads 타겟 마케팅에 적합

### 한 줄 정의 (제안서용)

> 본 프로젝트는 거주지의 일시적 단절을 겪지만 향후 동일 지역으로 회귀하는 **「시즌성 주거 노마드」**의 공백기 짐 보관 문제를 해결하고자 한다.

### 타겟 세그먼트 명칭 후보

| 명칭 | 의미 |
|------|------|
| 리턴 족 (The Returners) | 방학·출장 후 동일 지역으로 회귀하는 유저 |
| 주거 노마드 (Housing Nomad) | 시즌·프로젝트에 따라 거주지를 옮기는 현대인 |
| 공백기 거주자 (Intermission Consumer) | 거주 계약 사이 공백을 지나는 사람 |
| 앵커 족 (The Anchorers) | 특정 지역에 기반을 두고 잠시 외출하는 사람 |

### STP — 세그먼트

| 세그먼트 | 발생 상황 | 시점 | 밀집 지역 | 핵심 니즈 |
|----------|-----------|------|-----------|-----------|
| **A. 대학 기숙사생** (메인) | 방학 기간 기숙사 퇴소 | 6월·12월 중순 | 대학 캠퍼스 반경 3km | 2.5~3개월 보관, 픽업, 전공서적·계절의류 |
| **B. 계절성/단기 근로자** (서브) | 스키장·서핑·단기 인턴 | 11~12월, 5~6월 | 강원·제주·판교·강남 | 좁은 숙소, 대형 장비 보관 |
| **C. 장기 출장자·연구원** | 파견·프로젝트 이동 | 연중 상시 | 대덕·판교·세종 등 | 고가 기기 보안, 비용 증빙 |

**Targeting:** 메인 A(대학 기숙사생), 서브 B(계절성/단기 근로자)

**Positioning:** 고객의 짐을 비용이 아닌 **자산**으로 전환 — 문 앞 픽업 → 보관 → 위탁 대여 → 수익 정산 → 재배송까지 한 번에 연결

## 1.2. 문제정의 및 가설

### 문제 정의 (Pain Point)

#### 거주지와 삶의 인프라 간의 일시적 단절

방학 퇴소, 입주 대기, 장기 출장 등으로 집을 비워야 할 때 발생하는 문제:

1. **리소스 및 비용 낭비**
   - 본가 왕복 택배, 쓰지 않는 방의 월세 유지, 헐값 처분 등 경제·물리적 비효율

2. **기존 창고 대여(다락 등)의 한계**
   - 직접 무거운 짐을 창고까지 운반해야 함 → 차량 없는 2030에게 진입장벽

3. **기존 중고 거래/대여(당근마켓 등)의 한계**
   - 개인 간 연락·일정 조율·포장·배송 피로감, 사기 위험

**Micro 관점 한 줄 문제:** *"방 빼라는데 내 짐은 어디로?"*

### 검증 가설 (6개)

| # | 가설 | 담당 |
|---|------|------|
| 1 | 주거 공백기 유저는 짐 보관·처리에 불편하고, 마땅한 대안이 없다 | 하연 |
| 2 | 단순 보관보다 **위탁 대여**에 관심을 보일 것이다 | 성웅 |
| 3 | 단기 임대·대여에 **이용료 지불 의향**이 있다 | 지웅 |
| 4 | 위탁 대여 시 **플랫폼 신뢰·의향**이 있다 | 승환 |
| 5 | 외부 이용자에게 **일시 대여 니즈**가 있다 | 지훈 |
| 6 | 기숙사생·자취생의 이동 시기에 **보관·처분 필요**가 증가한다 | 자영 |

### NSM (North Star Metric)

- **최종 NSM:** 보관서비스 사용자 확보를 통한 매출 증대
- **대안 NSM 후보:** 월간 주거 공백기 보관 성공 건수, 주거 공백기 유저당 평균 순 보관 비용(보관료 − 대여 수익)

## 1.3. 마케팅 전략 및 시장 분석

### 시장 규모·환경

| 지표 | 내용 |
|------|------|
| 1인가구 | 전국 804만 가구(36.1%), 서울 39.9%, 2030 비중 35.2% |
| 기숙사 수용률 | 전국 22.2%, 수도권 17.8% → 재학생 5명 중 4명 학교 밖 거주 |
| 수도권 잠재 수요 | 재학생 65.5만 명 중 기숙사 11.8만 명 수용 → **약 53만 명** 매 학기 짐·이동 수요 |
| 2030 이동 | 20·30대 이동률 전 연령 최고, 서울 20대 순유입 1위 |
| 청년 주거 | 수도권 임차 80~85%, 원룸·오피스텔 비중 높음 |
| 셀프스토리지 | 국내 이용률 가구 대비 1% 미만, 2034년 0.4~2.1조 원 성장 전망, 월 약 10만 원 |
| 경쟁사 | 다락, 아이엠박스(250호점+), 빌릿지(물품 대여), 캠터 |

### SWOT 분석 (통합본)

#### Strengths (강점)

- 문 앞 픽업부터 보관·대여·정산·재배송까지 연결되는 올인원 편의성
- 보관 중 유휴 물품을 타인에게 대여하여 보관료 상쇄·추가 수익 가능
- 기숙사 퇴소 등 **반복적·예측 가능한 수요** 타겟
- USER RESEARCH로 청년층 보관·대여 수요 검증

#### Weaknesses (약점)

- 물품 파손·분실·위생에 대한 높은 신뢰 장벽
- 초기 브랜드 인지도·플랫폼 신뢰도 부족
- 물류·창고·검수 중심의 높은 운영 난이도와 비용
- 공급자(보관)와 수요자(대여) 동시 확보 필요 — 양면시장

#### Opportunities (기회)

- 1인가구·청년 이동·주거비 상승에 따른 단기 보관 수요 증가
- 공유경제·렌탈·중고거래 문화 확산 (MZ세대)
- 셀프스토리지 시장 성장, 이용률 1% 미만 → 차별화 여지
- 대학가·원룸촌 중심 지역 밀착 마케팅 가능

#### Threats (위협)

- 다락·아이엠박스 등 기존 보관 서비스의 유사 기능 확장
- 당근마켓 등 지역 기반 플랫폼의 대여 기능 강화
- 대형 물류·이커머스 기업의 단기 보관 시장 진입
- 분실·파손 이슈 시 브랜드 신뢰 하락, 시즌 수요 편중(6·12월)

#### SWOT 기반 전략

| 전략 | 내용 |
|------|------|
| **SO** | 기숙사 퇴소 시즌 대학가 집중 공략, 「보관료 0원 챌린지」 캠페인 |
| **ST** | 셀프 창고의 불편함 공략 — "짐 싸서 어디로 가세요? 문 앞에 두면 끝" |
| **WO** | 대학가 제한 운영으로 물류 부담 축소, 검수·보상 체계 단계적 고도화 |
| **WT** | 대여 품목 제한, 보험·보상 기준 명확화, 초기엔 보관 중심 후 대여 확장 |

### 4P 마케팅 전략 (통합본)

| 4P | 전략 | 세부 |
|----|------|------|
| **Product** | 문 앞 픽업 + 단기 보관 + 위탁 대여 | 픽업, 검수, 사진 기록, 보관 현황, 대여 등록, 수익 정산, 재배송 |
| **Price** | 보관료 부담을 낮추는 수익화형 구조 | 월 구독·박스 단위(소형 5,900원~), 방학 2~3개월 패키지, **보관료 − 대여 수익 = 실부담** |
| **Place** | 대학가·주거 이동 수요 지역 중심 | 캠퍼스 3km, 원룸촌·오피스텔, 앱/웹 접점 |
| **Promotion** | 주거 공백기 문제 해결 + 보관료 절감 | 6·12월 퇴소 시즌, 에타·인스타·검색광고, 공감형 콘텐츠 |

## 1.4. 제안 솔루션 및 서비스 전략

### Solution ① 문 앞 비대면 픽업 & 공간 구독

- 배달 앱 형태의 비대면 수거·배송
- 0.3~0.5평 등 **평수/부피 기준 월 구독** 요금제
- 차량 없는 2030의 물리적 마찰 제거

### Solution ② 플랫폼 풀-위탁(Full-Withholding) 대여

- 보관 중 **「대여 동의」** 한 번으로 플랫폼이 검수·등록·배송·정산 대행
- **상업적 메시지:** "짐 맡겨서, 노는 짐으로 돈 벌어가세요" / "숨만 쉬어도 월 OO원이 내 지갑으로"
- 보관료(지출)보다 대여료(수익)가 커지는 **자산 선순환 구조** → 플랫폼 락인 유도

### 초기 운영 품목

소형가전, 생활용품, 계절용품, 캠핑용품, 소형 가구, 모니터·전기포트 등 **파손 위험 낮고 대여 수요 있는 품목**

### 신뢰 장치 (USER RESEARCH 기반)

| 순위 | 기능 |
|------|------|
| 1 | 실시간 보관 상태 확인 |
| 2 | 후기 시스템 |
| 3 | 신원 인증 |
| 4 | 사진 기록 |
| 5 | 보험·보상 체계, CCTV |

### 브랜드 아이덴티티

- **서비스명:** 짐토리 (짐 + 스토리)
- **캐릭터:** 햄스터 — 볼 주머니에 짐을 안전하게 모으는 이미지
- **톤:** 2030·대학생·취준생·1인가구에게 친근하고 가벼운 브랜드

### 발표 기획 방향 (3부 구성)

| 파트 | 내용 |
|------|------|
| **1부** | 문제정의, 가설 검증 (공공데이터, 크롤링, USER RESEARCH 106명, STP) |
| **2부** | 서비스 전략 (브랜드, 4P, 프로토타입, NSM·퍼널) |
| **3부** | 성과 검증 (Meta 광고 A/B, GA4, Zapier) |

#### 파트별 핵심 메시지

- **1부:** "대학생들의 방학 시기 주거 공백은 매년 반복되는 확정된 불편함입니다. 저희는 이를 데이터로 증명했습니다."
- **2부:** "짐토리는 돈을 쓰는 창고가 아닙니다. 안 쓰는 동안 돈을 벌어다 주는 내 방의 확장판입니다."
- **3부:** "가설에만 그치지 않고, Meta 광고와 GA4로 유저의 지불 의향 행동을 데이터로 확인했습니다."

## 2.3. 분석 결과 및 인사이트

### 크롤링 통합 인사이트

**한 줄 결론:** 학기 전환기(2·6~8월)에 **강제 주거 공백 → 짐 처리·운반·단기 거주의 묶음 마찰**이 반복 검증됨. 사용자는 「짐보관 서비스」를 인지하지 못한 채 불편만 호소. **진입 우선순위: 물품(가전) 대여**, 핵심 메시지: **「문 앞 픽업」**.

#### 가설별 크롤링 검증 결과

| 가설 | 결과 | 근거 |
|------|------|------|
| **H2 주거 공백기** | 강하게 검증 | 네이버 n=738 (최다), 지식인 31% |
| **H3 물품 대여** | 검증 (행동 임박도 최고) | 네이버 n=441, 지식인 37%, 전자제품·가구·에어컨 |
| **H1 짐보관** | 검증되나 공급 노이즈 | 네이버 n=354, 다락·셀프스토리지 마케팅 혼재 |

#### 에타 페인포인트 정량화 (n=193)

| Pain Point | 건수 | 비율 | 대표 발화 |
|------------|------|------|-----------|
| 택배 이용 어려움 | 74 | 38.3% | 박스·우체국·방문수거 |
| 지방 출신 이동 부담 | 42 | 21.8% | 왕복 9시간, 부모 차 의존 |
| 입퇴소 시기 짐 처리 | 28 | 14.5% | 퇴사일 짐 빼기 |
| 이동 수단 없음 | 15 | 7.8% | 혼자 올라가야 해서 |
| 보관 장소 없음 | 5 | 2.6% | 학교 내 창고 없음 |

#### 크롤링 핵심 인사이트 5가지

1. **지방 출신 기숙사생** — 방학마다 이동비+짐 이중 부담, 입·퇴소 시즌 기숙사 앞 픽업 유효
2. **초단기 공백(3~5일)** — 퇴소~재입소 사이 브릿지 보관 수요, 별도 요금제 검토
3. **짐보관 서비스 인지 0건** — 「기숙사 퇴소」「방학 짐 처리」 등 상황 키워드로 마케팅
4. **6월 이사처분 피크** — 당근 6월 2,301건(연 23%), 위탁 대여 공급원
5. **위탁 대여 동기** — 보관료 상쇄 + 소액 수익, 대여료를 판매가 5~10%/1회로 설계 시 매력

#### Pain Point (복수응답)

운반 어려움, 보관 공간 부족, 적절한 서비스 찾기 어려움, 처분 번거로움, 보관 비용 부담, 지인 부탁 부담

**핵심:** Storage보다 **Logistics**(운송·관리) 문제가 더 큼

#### 대여 관련

- 선호 이유 1위: **일회성 사용** (전공책, 모니터, 면접 정장, 계절가전)
- 2위: 구매 비용 부담
- 우려: 연락·직거래 피로, 성능·고장, 위생, **파손 책임**

| 전략 레이어 | 데이터 근거 | 시사점 |

| **USP** | 택배 불만 74건, 부모 차 의존 15건 | **「문 앞 픽업」** 단일 메시지 |
| **가격** | 가격 1위, 단기임대 5~15만 원 | 보관료+대여 환급으로 실질 비용 0원 접근 |
| **채널** | 짐보관 직접 검색 0~3건 | 에타·상황 키워드 선점 |
| **제품** | 물품대여 kin 37% 최고 | **「보관 + 단기 가전대여」** 묶음 차별화 |
| **초단기** | 퇴소~재입소 3~5일 공백 | 브릿지 보관(1주 이하) 별도 요금제 |

### USER RESEARCH 최종 인사이트 5가지

1. 고객은 **수거 → 보관 → 대여 → 처분**까지 연결되는 **통합 생활물류 플랫폼**을 원함
2. 최대 Pain Point: **운반과 비용** → Door-to-Door 수거 + 합리적 가격이 핵심
3. 선택 기준: **가격 + 운반 서비스 + 신뢰도**
4. 신뢰: 실시간 확인, 사진, 보험, 후기, 신원 인증
5. 대여: 시장 수용성 높음, **보험·보상 없으면 참여율 급감**

### 향후 데이터 파이프라인 (노션 기록)

- **GA4:** 픽업 신청, 대여 동의, 정산 확인 등 커스텀 이벤트
- **BigQuery → Data Studio:** 퍼널·행동 시각화
- **Meta Ads A/B:** 단순 보관 vs 수익형 메시지 CTR·CPC
- **ML (설계 단계):** 창고 포화도 예측, 체적 자동 측정, 동적 배치

## 요약

**짐토리**는 1인가구 전체가 아니라 **「주거 공백기」**에 집중한 **문 앞 픽업 + 위탁 대여** 플랫폼이다.

### 마케팅 핵심

- **타겟:** 대학 기숙사생 (메인), 계절성 근로자 (서브)
- **포지션:** 짐을 비용이 아닌 자산으로 전환하는 마이크로 스토리지
- **메시지:** 「문 앞 픽업」「보관료 상쇄」「방학 때 짐, 본가까지 가져가지 마세요」
- **시즌:** 6월·12월 퇴소 전후 집중 마케팅

### 데이터 핵심

- **수요 검증:** 크롤링 1.2만+건, 설문 106명, 공공통계
- **페인:** 운반·택배·이동 (보관 공간 자체보다 Logistics)
- **전환 요인:** 가격, 문 앞 픽업, 실시간 보관 확인, 보험·보상
- **차별화:** 보관 + 위탁 대여 + 픽업 통합, 경쟁 셀프스토리지 대비 편의성

### 서비스 본질

창고 사업이 아니라 **청년 주거 이동 문제를 해결하는 물류·자산 관리 플랫폼**이다.
