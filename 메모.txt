1. 우리가 설정한 메인 타겟											
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━											
											
[한 줄 정의]											
  「시즌성 주거 노마드」— 거주지가 일시적으로 비는 사람을 위한											
  문 앞 픽업 + 보관 + 위탁 대여 플랫폼											
											
[STP — 메인 타겟]											
  ■ 세그먼트 A: 대학 기숙사생 (메인)											
    - 상황: 방학·퇴소 시 기숙사에서 나와야 하는 경우											
    - 시점: 6월·12월 중순 (매 학기 반복)											
    - 지역: 대학 캠퍼스 반경 3km											
    - 니즈: 2.5~3개월 보관, 픽업, 전공서적·계절의류											
											
  ■ 공통 페르소나 특성											
    - 20대 중심 / 1인 가구 / 주거 이동 경험 92.5%											
    - 짐 보관 필요 경험 88.7% / 서비스 이용 의향 87.7%											
																					
											
[발표에서 강조할 포인트]											
  → 우리는 처음부터 「1인가구 전체」가 아니라											
    「주거 공백기」라는 상황적 세그먼트에 집중했다.											
  → 기숙사생은 이 세그먼트의 대표 사례이며, 가장 예측 가능한 수요(6·12월)를 가진다.											
											
											
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━											
2. 머신러닝을 통해 알아내고자 했던 것											
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━											
											
[핵심 질문]											
  Q1. 어떤 유저 Feature가 서비스 선호(Y/N)와 연결되는가?											
  Q2. 대학생·기숙사생이 아닌 사람도 짐토리의 고객이 될 수 있는가?											
											
[검증 목적 — 세그먼트 확장 가능성]											
  현재 메인 타겟(대학생)에만 머물지 않고,											
  STP 서브 타겟(B: 계절근로자, C: 장기출장자) 및											
  직장인·취준생으로 사업을 확장해도 되는지 데이터로 검증											
											
[분석 설계 요약]											
  - 데이터: User Research 설문 106명											
  - 타깃(Y): Q6 이용의향 4점 이상 → 선호(1) / 비선호(0)											
  - Feature(X): 인구통계 4개 + 행동·니즈 10개 (총 14개)											
  - 모델: Logistic Regression(해석) + Random Forest(예측)											
  - 검증: 5-Fold 교차검증 + STP 프로필 시뮬레이션 + 대학생 모델 전이 테스트											
											
[발표 멘트 예시]											
  "가설과 리서치로 수요는 확인했습니다.											
   이제 ML로 '누가, 왜, 선호하는지'를 수치화하고,											
   메인 타겟 밖의 고객도 같은 패턴을 보이는지 검증했습니다."

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Google Forms 설문 106명 응답을 xlsx로 불러와											
  성별·연령·직업·가구·Q1~Q9·대여/위탁 항목으로 컬럼 정리											
											
[인사이트]											
  - 20대 61%, 1인 가구 61%, 대학생 45%											
  - 메인 타겟 + 확장 검증에 필요한 직장인(25%)·취준생(18%)이 함께 포함

STEP 2. Feature Engineering											
──────────────────────────────────────────────────────────────────────────────											
[설명]											
  설문 응답을 ML Feature로 변환											
											
  [인구통계] 성별, 연령대, 직업, 가구형태											
  [행동·니즈] 이동빈도, 보관니즈, 페인점수, 신뢰점수											
  [플래그] 대여경험, 위탁참여의향, 운반/공간/비용 페인											
											
  [타깃 Y] service_preference = Q6 이용의향 ≥ 4점 → 1(선호)											
											
[인사이트]											
  - 전체 서비스 선호율: 88.7% (94/106명)											
  - 단순 인구통계가 아니라 「상황」을 담는 행동 변수가 핵심											
  → 크롤링·리서치 결론(운반·이동 페인)과 Feature 설계가 일치											
											
──────────────────────────────────────────────────────────────────────────────											
STEP 3. EDA — 응답자 프로필 & 행동 분포											
──────────────────────────────────────────────────────────────────────────────											
[설명]											
  인구통계 파이/바 차트, 이동·니즈·페인·신뢰 박스플롯으로 분포 확인											
											
[인사이트]											
  - 보관 니즈·불편도 모두 4~5점대에 몰림 → 수요가 강함											
  - 이동 빈도 1~3회가 다수 → 반복적 주거 이동 경험 보유											
  - 신뢰 점수 분산 → 플랫폼 신뢰 장치(실시간 확인·보험)가 전환 관건											
  → "보관 공간 부족"보다 "운반·이동·비용" Logistics 문제가 더 큼

STEP 4. 세그먼트별 실측 선호율											
──────────────────────────────────────────────────────────────────────────────											
[설명]											
  직업·가구형태별로 서비스 선호율(Y=1 비율) 산출											
											
[핵심 수치]											
  직장인      n=26  →  100%											
  자영업자    n=7   →  100%											
  대학생(메인) n=48  →  89.6%											
  취업준비생  n=19  →  84.2%											
  프리랜서    n=5   →  40% (표본 작음)											
											
  메인(대학생) 89.6%  vs  확장(비대학생) 87.9%											
											
[인사이트]											
  ★ 발표 핵심 숫자 ★											
  "대학생만 선호하는 서비스가 아니다."											
  비대학생도 87.9%로 메인 타겟과 거의 동일한 선호를 보임.											
  특히 직장인 100% → 확장 1순위 근거											
											
  직업 × 1인가구 조합에서 선호율 최고											
  → 확장 시 「직업」보다 「1인가구 + 주거 공백기」 메시지가 유효

STEP 5. ML 모델 학습 & 교차검증											
──────────────────────────────────────────────────────────────────────────────											
[설명]											
  Logistic Regression + Random Forest, 5-Fold CV											
  Baseline: 인구통계 4개만 사용한 모델과 비교											
											
[핵심 수치]											
  Demographics Only  →  ROC-AUC 0.760											
  Logistic Regression → ROC-AUC 0.845											
  Random Forest        → ROC-AUC 0.894  ← 채택											
											
[인사이트]											
  - 행동 Feature 추가 시 AUC 0.76 → 0.89 (약 +17%p)											
  - 「누구냐」보다 「어떤 상황이냐」가 선호를 더 잘 설명											
  → 포지셔닝: "대학생 서비스" X → "주거 공백기 서비스" O

STEP 6. Feature Importance & 계수 해석											
──────────────────────────────────────────────────────────────────────────────

[상위 영향 요인]											
  1. pain_score (불편 정도)											
  2. trust_score (플랫폼 신뢰)											
  3. 1인 가구											
  4. move_frequency (이동 빈도)											
  5. storage_need_score (보관 니즈)											
											
[선호를 높이는 요인 (+)]											
  - 위탁 대여 참여 의향, 보관 공간·비용 페인, 신뢰, 이동 빈도											
  - occupation_직장인 (직장인 세그먼트)											
											
[인사이트]											
  전환 공식 = 높은 페인 + 잦은 이동 + 신뢰 + (선택) 위탁 대여											
  USER RESEARCH 1위 요인(가격·운반·신뢰)과 ML 결과가 정합											
  → 제품은 「창고」가 아니라 「문 앞 픽업 + 신뢰 + 수익 환급」 패키지

STEP 7. STP 확장 프로필 예측 (시뮬레이션)											
──────────────────────────────────────────────────────────────────────────────											
[설명]											
  학습된 RF에 STP 시나리오별 가상 프로필을 입력해 선호 확률 예측											
											
[예측 결과]											
  A. 20대 대학생 1인가구 (메인)     →  97.3%  ✅											
  B. 30대 프리랜서 1인가구 (계절근로) →  73.2%  ✅											
  C. 30대 직장인 1인가구 (장기출장)  →  64.2%  ✅											
  취준생 20대 2인가구               →  38.4%  ❌											
  40대 직장인 4인가구               →  18.5%  ❌											
											
[인사이트]											
  STP 서브 타겟 B(계절근로)·C(장기출장) 확장 타당											
  성공 조건: 1인 가구 + 높은 이동·페인·니즈											
  4인 가구·저니즈 프로필은 초기 GTM에서 제외

STEP 8. 대학생 모델 → 비대학생 전이 예측

[설명]											
  대학생 48명만으로 모델 학습 → 비대학생 58명에 예측 적용											
  "메인 타겟에서 배운 패턴이 다른 세그먼트에도 통하는가?" 검증											
											
[인사이트]											
  - 1인 가구 직장인·취준생: 예측 60~95% (실제 선호와 일치)											
  - 실패 케이스: 4인 가구, 프리랜서(표본 n=5), 고연령											
  → 직업이 달라도 「주거 공백기 + 1인가구」면 동일 전환 패턴											
  → 확장 시 직업 타겟팅보다 상황 타겟팅(이사·출장·방학)이 적합

4. 전체적인 결과 및 결론											
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━											
											
[핵심 발견 4가지 — 발표 슬라이드용]											
											
  ① 짐토리는 대학생만의 서비스가 아니다											
     메인 89.6% vs 확장 87.9% — 통계적으로 유의미한 격차 없음											
     직장인 실측 선호율 100%											
											
  ② 고객의 본질은 「시즌성 주거 노마드」											
     1인 가구 + 주거 이동 + 보관 니즈 + Logistics 페인											
     직업 라벨보다 「상황」이 전환을 결정											
											
  ③ 전환 레버는 명확하다											
     가격 + 문 앞 픽업(운반) + 실시간 보관 확인 + 보험·보상											
     ML + USER RESEARCH 양쪽에서 동일 결론											
											
  ④ 확장은 가능하며, 순서가 있다											
     Phase 1: 대학생·기숙사생 (6·12월)											
     Phase 2: 20~30대 직장인 1인가구 (출장·파견)											
     Phase 3: 취준생·프리랜서 (이사·계절근로 파일럿)											
											
[사업 확장 로드맵]											
											
  Phase 1 (현재)   대학가 3km · 기숙사 퇴소 시즌 · 에타·검색광고											
  Phase 2 (6개월)  직장인 1인가구 · 「출장·파견 시 짐 보관」메시지											
  Phase 3 (12개월) 취준생·계절근로 · 이사·면접·제주/강원 파일럿											
											
[마케팅 메시지 전환 제안]											
											
  Before: "대학생 짐보관 서비스"											
  After:  "주거 공백기, 문 앞 픽업으로 끝"											
											
[한계 및 보완 (발표에서 선제 언급)]											
											
  - n=106, 편의 표집 → 절대 확률보다 세그먼트 간 상대 비교 중심											
  - 프리랜서 n=5 → 추가 검증 필요											
  - 다음 단계: GA4 실전환(픽업신청·위탁동의)으로 Y 변수 고도화											
  - Meta Ads A/B로 직장인·취준생 랜딩 검증											
											
[가설 검증 종합 — 기존 H1~H6 + ML 연결]											
											
  H1 주거 공백기 페인     → ✅ pain_score·move_frequency 상위											
  H2 위탁 대여 관심       → ✅ consignment_positive 양(+) 계수											
  H3 지불 의향            → ✅ 선호율 88.7%, 가격 민감(리서치)											
  H4 플랫폼 신뢰          → ✅ trust_score 2위 중요도
